# ChunkTrainer v1.1.0

## ما الجديد

- إصلاح اتجاه كتابة الألماني والعربي في خانات «غيّر كل مرة» والتفاف الجمل الطويلة.
- منع تكرار تنبيه «اكتب جملة الأول» عند الضغط المتتابع، مع تحديد الخانة التي تحتاج كتابة.
- مزامنة تحسينات النسخة المكتبية الحالية: عرض حالة الجلسات، التنقّل بين الجمل، وإغلاق نوافذ التدريب عند الانتقال بين الصفحات.
- الحفاظ على سجلات التقدم في B2 وC1 أثناء تحميل البيانات؛ لا تُحذف السجلات لمجرد عدم وجود تنويعات أو ملاحظات.
- توفير ملف تثبيت Windows ونسخة محمولة يحتويان على Electron والأصول المحلية.

## التثبيت

حمّل `ChunkTrainer-Setup-1.1.0-x64.exe` للتثبيت، أو `ChunkTrainer-Portable-1.1.0-x64.exe` للتشغيل المباشر. التطبيق يعمل بدون Node.js أو متصفح خارجي، ويحفظ بيانات التقدم في مجلد خاص بالمستخدم خارج ملفات البرنامج.

إذا كنت تستخدم نسخة قديمة، أغلقها قبل تشغيل النسخة الجديدة. احتفظ بنسخة من تقدمك عبر «الإعدادات ← تصدير البيانات» قبل أي إعادة تثبيت.
